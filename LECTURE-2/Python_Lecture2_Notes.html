Strings

A data type that stores a sequence of characters

Definition

What is a String?

A string is a sequence of characters enclosed in quotes. In Python, you can use single '' or double "" quotes.

python
# Creating strings
name   = "Apna College"
city   = 'Delhi'
empty  = ""          # empty string
Basic Operations

Concatenation & Length

python
# Concatenation — joining strings with +
s1 = "hello"
s2 = "world"
result = s1 + s2
print(result)   # helloworld

# Add space between
result2 = s1 + " " + s2
print(result2)  # hello world

# Length — number of characters
name = "Apna College"
print(len(name))  # 12

# Repetition with *
print("ha" * 3)    # hahaha
💡 Note: Strings are immutable in Python — you cannot change individual characters once created.

Slicing

Extracting a portion of a string

Syntax

str[ start : end ]

Returns characters from start up to but not including end.

python
str = "ApnaCollege"

str[1:4]        # "pna"   → indices 1,2,3 (4 excluded)
str[0:4]        # "Apna"
str[4:11]       # "College"

# Omitting start → defaults to 0
str[:4]         # "Apna"  (same as str[0:4])

# Omitting end → defaults to len(str)
str[4:]         # "College" (same as str[4:len(str)])

# Copy entire string
str[:]          # "ApnaCollege"
Negative Index Slicing

Slice from the end

python
str = "Apple"
#  A  p  p  l  e
# -5 -4 -3 -2 -1

str[-3:-1]    # "pl"   → indices -3,-2 (-1 excluded)
str[-3:]     # "ple"  → from -3 to end
str[:-1]     # "Appl" → all except last
Step Slicing (Bonus)

str[ start : end : step ]

python
str = "ApnaCollege"

str[::2]      # Every 2nd char: "AnClee"
str[::-1]     # Reverse the string: "egelloCanpA"

# Quick way to reverse any string!
reversed_str = str[::-1]
💡 Tip: str[::-1] is the most Pythonic way to reverse a string — memorize it!

String Functions

Built-in methods to manipulate strings

Quick Reference

Common Methods

MethodWhat it doesReturns
str.upper() Converts all characters to uppercase String
str.lower() Converts all characters to lowercase String
str.capitalize() Capitalizes only the first character String
str.endswith(sub) Checks if string ends with the given substring True / False
str.find(word) Returns index of first occurrence (−1 if not found) Integer
str.replace(old, new) Replaces all occurrences of old with new String
str.count(sub) Counts how many times substring appears Integer
str.strip() Removes whitespace from both ends String
str.split(sep) Splits string into a list by separator List
Code Examples

All Methods in Action

python
str = "I am a coder."

# endswith — check suffix
print(str.endswith("er."))       # True
print(str.endswith("xyz"))       # False

# capitalize — first char uppercase
print("hello world".capitalize()) # Hello world

# upper / lower
print(str.upper())               # I AM A CODER.
print(str.lower())               # i am a coder.

# find — index of first occurrence
print(str.find("am"))           # 2
print(str.find("xyz"))          # -1 (not found)

# replace — swap all occurrences
print(str.replace("coder", "developer"))
# I am a developer.

# count — how many times does "a" appear?
print(str.count("a"))           # 2

# strip — remove surrounding spaces
messy = "   hello   "
print(messy.strip())             # "hello"

# split — break into list
words = str.split(" ")
print(words)   # ['I', 'am', 'a', 'coder.']

Conditional Statements

Make decisions in your program with if-elif-else

Syntax

if — elif — else

Python uses indentation (4 spaces) instead of curly braces to define blocks.

python
if(condition):
    Statement1          # runs if condition is True
elif(condition):
    Statement2          # runs if above was False, this is True
else:
    StatementN          # runs if ALL above were False
⚠️ Indentation matters! Python uses whitespace to define code blocks. Always use consistent 4-space indentation.
Example 1

Grade Calculator

python
marks = int(input("Enter marks: "))

if marks >= 90:
    grade = "A"
elif marks >= 80:
    grade = "B"
elif marks >= 70:
    grade = "C"
else:
    grade = "D"

print("Your grade:", grade)

# marks=95 → A
# marks=83 → B
# marks=72 → C
# marks=55 → D
Example 2

Odd or Even

python
n = int(input("Enter a number: "))

if n % 2 == 0:
    print(n, "is Even")
else:
    print(n, "is Odd")
Example 3

Greatest of 3 Numbers

python
a = int(input("Enter 1st number: "))
b = int(input("Enter 2nd number: "))
c = int(input("Enter 3rd number: "))

if a >= b and a >= c:
    print("Greatest:", a)
elif b >= a and b >= c:
    print("Greatest:", b)
else:
    print("Greatest:", c)

# Short way using max()
print("Greatest:", max(a, b, c))
