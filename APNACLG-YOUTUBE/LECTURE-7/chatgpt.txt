1️⃣ r → Read Mode
Purpose: Open file only for reading. File must exist.

file = open("data.txt", "r")
content = file.read()
print(content)
file.close()
✅ Reads content from data.txt.

2️⃣ w → Write Mode
Purpose: Write into file.
⚠️ If file exists → old content is deleted.

file = open("data.txt", "w")
file.write("Hello World")
file.close()
✅ Creates file if not present
❌ Deletes previous data

3️⃣ x → Create Mode
Purpose: Create new file only.

file = open("newfile.txt", "x")
file.write("This is a new file")
file.close()
✅ File created
❌ Error if file already exists

4️⃣ a → Append Mode
Purpose: Add data at the end of file.

file = open("data.txt", "a")
file.write("\nThis line is appended")
file.close()
✅ Old content remains
✅ New content added at end

5️⃣ r+ → Read and Write
Purpose: Read and write in same file.

file = open("data.txt", "r+")
print(file.read())
file.write("\nAdded using r+")
file.close()
✅ Can read
✅ Can write
❌ File must exist

6️⃣ w+ → Write and Read
Purpose: Read and write but old data is erased first.

file = open("data.txt", "w+")
file.write("New content")
file.seek(0)
print(file.read())
file.close()
✅ File cleared first
✅ Then write + read

7️⃣ a+ → Append and Read
Purpose: Read and append data at end.

file = open("data.txt", "a+")
file.write("\nNew line added")
file.seek(0)
print(file.read())
file.close()
✅ Existing content remains
✅ New data added at end
✅ Can read file

8️⃣ b → Binary Mode
Used for images, videos, audio files.

file = open("image.jpg", "rb")
data = file.read()
print(data)
file.close()
✅ Reads binary data

9️⃣ t → Text Mode (Default)
Used for text files.

file = open("data.txt", "rt")
print(file.read())
file.close()
Same as:

open("data.txt")
🔟 Binary Write Example (wb)
file = open("image_copy.jpg", "wb")
file.write(b"Binary data example")
file.close()
Used for writing binary files.

w+	Write + Read (delete old data)

1️⃣ r+ → Read + Write (start of notebook)
Imagine a kid opens the notebook.

The kid can read what is written

The kid can change or write on the same page

But the notebook must already exist.

Example idea:

Open notebook → read it → write something on the page.

So:

r+ = read + write (start of file, no deleting old pages)

2️⃣ w+ → Write + Read (erase notebook first)
Now imagine the kid opens the notebook and erases everything first ✏️❌

Then:

Writes new things

Can also read them

So:

w+ = erase notebook → write new → read

3️⃣ a+ → Add at the end
Imagine the notebook already has many pages.

The kid cannot erase anything.

The kid can only:

read the notebook

add a new line at the end

So:

a+ = read + add new lines at the end

Super Tiny Memory Trick 🧠
Think of a notebook 📒

Mode	What the kid does
r+	read and change pages
w+	erase notebook then write
a+	add new lines at end
